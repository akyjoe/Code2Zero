About the Super Intelligent Tools Footprint Inspector

How this estimate works

TheCreatology Super Intelligent Tools Footprint Inspector estimates text volume with a simple character-based heuristic of roughly one token per four characters. When lines use role labels such as “User:” and “Assistant:”, it estimates input and output separately. The selected workload assumptions are applied to estimate electricity use, associated carbon dioxide equivalent emissions, and water use.

Privacy and browser-only processing

This is a client-only prototype. Pasted text and calculations stay in this browser session; the page does not send conversation text to a backend, super intelligent tools provider, or external API. Nothing is stored on prototype servers. Use care with sensitive or personal information when pasting any conversation into a web page.

Assumptions and limitations

These values are illustrative scenario estimates, not measurements or claims about any named super intelligent tools company. This tool cannot recover hidden system prompts, model-specific tokenization, image, audio, or video processing, cached tokens, hardware utilization, data-centre location, or real-time energy use. Actual impacts depend on the model, infrastructure, workload, cooling, and electricity mix. Results are directional scenarios, not audited carbon accounting.

What the results mean

Token totals describe an approximate text-token equivalent. Energy, emissions, and water figures follow the editable assumptions in the settings panel. Changing those assumptions changes the scenario; it does not reveal a provider’s actual resource use.
