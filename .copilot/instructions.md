# Code2Zero — Soul File

This file defines the standing rules that apply to every conversation about this project. Treat them as non-negotiable project conventions.

## Commit Rules

1. **Never commit with a co-author tag.** Do not add `Co-authored-by` trailers unless the user explicitly asks for them.
2. **Always ask before committing.** Do not run `git commit` without the user's explicit go-ahead.
3. **Always add a commit title with a funny carbon fun fact.** The title should open with a lighthearted, carbon/sustainability-themed fun fact (e.g. "🌱 Fun fact: one Google search emits ~0.2g CO2 — 50 searches equal one sugar cube of carbon").
4. **Always add a commit description with a list of changes.** The body should enumerate each file changed and what was changed in it.

## Project Context

Code2Zero is an open-source, low-footprint developer toolset for sustainable AI and software. Its flagship is the Super Intelligent Tools Footprint Inspector — a browser-based prototype that estimates the electricity, carbon, and water footprint of AI conversations.

Core ethos: Count the tokens. Show the carbon. Grow something green.
