MCP Server — Step-by-Step

Zero-auth stdio MCP server. No API keys, no backend, no build tools.

Option 1 — Run via npx (no install)

npx -y github:akyjoe/code2zero thecreatology-carbon-footprint

Downloads and runs the MCP server directly from GitHub. Works with any MCP-compatible client.

Option 2 — Run locally from clone

git clone https://github.com/akyjoe/Code2Zero.git
cd Code2Zero
npm install
node mcp/mcp.js

The server speaks MCP over stdio — connect your AI client to it.

Option 3 — Configure an AI client

Add to your client's MCP config (e.g. mcp.json or claude_desktop_config.json):

{
  "mcpServers": {
    "thecreatology-carbon-footprint": {
      "command": "npx",
      "args": ["-y", "github:akyjoe/code2zero", "thecreatology-carbon-footprint"]
    }
  }
}

Then invoke estimate_ai_footprint with your conversation text.

Tool: estimate_ai_footprint

Parameter Type Default Description
text string — AI conversation text to estimate
charsPerToken number 4 Characters per estimated token
whPerToken number 0.001 Watt-hours per token
co2PerWh number 0.45 g CO₂e per watt-hour
waterMlPerWh number 2 ml water per watt-hour

Returns: { tokens, electricity_wh, carbon_gco2e, water_ml, factors }

Source: mcp/mcp.js · Shared logic: formula.js · Zero authentication · Runs entirely via stdio
